# Personal Portfolio Website - Jonathan Kana Albertinus

Website portofolio pribadi yang responsif, interaktif, dan modern. Dibuat menggunakan HTML5, CSS3, dan Vanilla JavaScript dengan struktur desain berbasis *single-page layout* (iPortfolio style).

---

## 🚀 Fitur Utama

- **Sidebar Navigation Fixed**: Sidebar navigasi di sisi kiri (desktop) yang tetap berada di posisinya saat halaman di-scroll.
- **Responsive Mobile Navigation**: Menu *hamburger* interaktif untuk layar mobile/tablet dengan kustomisasi perubahan warna otomatis (putih/hitam) tergantung warna latar belakang section.
- **Dynamic Typewriter Effect**: Animasi pengetikan teks otomatis di area *Hero Section*.
- **Interactive Scroll Indicator**: Panah indikator dengan animasi *bouncing* untuk mengarahkan pengunjung menggulung halaman ke bawah.
- **Dynamic Active Link Highlight**: Navigasi sidebar otomatis menyorot menu yang sesuai secara real-time berdasarkan posisi scroll halaman.
- **Timeline Resume**: Tampilan riwayat pendidikan (*Education*) dan pengalaman (*Experience*) dalam format alur waktu 2 kolom yang rapi.
- **Direct Contact Cards**: Integrasi tautan langsung ke WhatsApp, Email (`mailto:`), dan lokasi tanpa form tambahan.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman semantik.
- **CSS3**: Layouting (*Flexbox* & *CSS Grid*), *animations*, `@keyframes`, dan *media queries* untuk responsivitas.
- **JavaScript (Vanilla ES6)**: Logika interaktivitas, *scroll listener*, *DOM manipulation*, dan animasi ketik.
- **FontAwesome v6.5.2**: Ikonografi untuk sosial media dan elemen antarmuka.
